# Projetos em destaque

### [Análise Exploratória de Dados Espaciais, ICVT São Luís](https://github.com/tamarardelima/icvt-aede-sao-luis)
Identificação de clusters geográficos de vulnerabilidade urbana em São Luís (MA) usando Moran's I e LISA aplicados a um Índice Composto de Vulnerabilidade Territorial calculado para 257 bairros.
`Python` · `GeoPandas` · `PySAL` · `Matplotlib`

### [Mapa Interativo, Vulnerabilidade Territorial em São Luís](https://github.com/tamarardelima/icvt-mapa-interativo)

Cartografia web do ICVT consultável por bairro, com alternância entre dimensões (social, infraestrutura, ambiental). Hospedado em GitHub Pages.

`Python` · `Folium` · `Branca` · `GitHub Pages`

[Abrir o mapa](https://tamarardelima.github.io/icvt-mapa-interativo)

### [Mudanças no Uso do Solo em São Luís, 1985 a 2022](https://github.com/tamarardelima/mudancas-uso-solo-sao-luis-1985-2022)

Análise multitemporal da expansão urbana e perda de cobertura vegetal em São Luís com dados do MapBiomas, cruzada com a vulnerabilidade territorial por bairro.

`Python` · `Rasterio` · `Google Earth Engine` · `MapBiomas`

### [Pipeline ETL Geoespacial, São Luís](https://github.com/tamarardelima/etl-geoespacial-sao-luis)

Pipeline reproduzível que integra Censo IBGE 2022, MapBiomas, Cartas de Suscetibilidade SGB/CPRM e shapefile de bairros num dataset analítico unificado.

`Python` · `GeoPandas` · `Rasterio` · `Pandas`
